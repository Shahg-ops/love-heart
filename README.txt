LOVE HEART - HTML/CSS/JS

1. Extract this folder.
2. Open it in VS Code.
3. Right-click index.html and choose Open with Live Server (or double-click index.html).
4. Optional music: place your own MP3 at assets/music.mp3.
5. Click Replay to start the animation again.

To slow/speed the text, change OUTLINE_DURATION and FILL_DURATION at the top of script.js.
No external libraries required.
